T3 Cardputer

Install T3 on your ADV

Run setup.sh on your T3 machine first

It sets up the relay and prints a link to this page. Open that link here.

curl -fsSL https://t3-cardputer.jopcmelo.com/setup.sh | sh

Already set up? Run t3-cardputer-relay install-link for a new link.

  1. Your relay

    Relay
    Pairing code
    Filled in

    The pairing code works for 10 minutes. If it runs out, run t3-cardputer-relay install-link and open the new link.

  2. Before you start

    This replaces everything on the ADV, Launcher included.

    Plug the ADV into this computer with a USB-C data cable.

  3. Off keeps the ADV's WiFi, relay and pairing. On erases them.
