T3 Cardputer

Your T3 Code agents on a Cardputer ADV

Answer approvals, read threads, talk to your agents and start new tasks from your pocket.

  1. 1. Set up your T3 machine

    curl -fsSL https://t3-cardputer.jopcmelo.com/setup.sh | sh

  2. 2. Install on the ADV

    Plug the ADV in over USB and open the link the script prints in Chrome or Edge.

  3. 3. Done

    The ADV restarts, joins WiFi and pairs by itself.
